# Authentication and Authorization Training

Authentication and Authorization are important concepts for security but most people don't know where to start.  
This training explains various auth protocols, and which ones you should use for the best security.

## Pre-requisites

This training will include a few hands-on demos.  
These demos will require the following:

- JDK 17 installed
- Kotlin configured

In order to follow along with the demos, make sure you clone this repository to a machine that meets the above
requirements.  
Before beginning, ensure that you can load and build the gradle project.
